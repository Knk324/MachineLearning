# MachineLearning
A basic machine learning code playground.

## Independent examples (basic to complex)

- `examples/01_linear_regression.py`  
  Basic univariate linear regression trained with gradient descent.
- `examples/02_logistic_regression.py`  
  Binary logistic regression from scratch (batch gradient descent).
- `examples/03_two_layer_neural_network.py`  
  A more complex two-layer neural network for XOR classification.
